1. この仕組みは何をしているか責任者

つながるまなびは、次の場面で生成AIを使っています。講師が「生成」ボタンを押すと、その都度AIの会社へ問い合わせが飛びます。

画面AIがしていること
報告書作成入力内容から保護者向けの報告書を書く／学習スキル17項目の下書きを付ける
カルテ報告書・テスト結果・保護者メッセージ・教材進捗を読み、その子の「今」をまとめる
テスト作成指定した学年・単元の問題をつくる
多層診断答案と自己申告から、つまずきの正体を1つに絞る
講習ビジョン講習の目標と計画を組み立てる
講師ホームその日の生徒ごとに「今日詰めること」を選ぶ
シフト割り当て結果の要約／行事予定の読み取り
⚠ ここが一番の誤解ポイントです

ChatGPT Plus や Claude Pro などの月額プランでは、つながるまなびは動きません。

月額プランは「人がチャット画面を使う権利」です。プログラムから呼ぶにはAPIキーという別の契約が必要です。 どれだけ月額プランを契約しても連携できません。ここは必ず分けてご説明ください。

2. どの鍵で動くか（3段の順番）責任者管理者

「誰の財布で払うか」を、上から順に試す仕組みになっています。

図1　鍵をどの順番で使うか
1社の鍵さえあれば、全機能が動きます

Claude・ChatGPT・Gemini のうちどれか1社の鍵があれば、すべての機能が動く作りにしてあります。 3社そろえないと使えない機能はありません。複数そろっている場合は、それぞれ得意な工程に振り分けて品質が上がります。

3. 無料で始めるか、有料にするか責任者

APIの無料枠を出しているのは実質1社だけです

提供元APIの無料枠備考
Google（Gemini）あり1分あたり・1日あたりの回数制限つき
OpenAI（ChatGPT）なし従量課金のみ
Anthropic（Claude）なし従量課金のみ

※ 無料枠の上限は各社の都合で変わります。ご案内の前に最新の条件をご確認ください。

結論：本運用は1社の有料に寄せる。無料枠は「お試しの入口」に使う

1社の有料に寄せる無料枠だけで回す
普段の1件ずつの生成問題なし問題なし
一括生成（全員ぶんのカルテ再作成など）最後まで通る数十件で回数制限に当たり止まる
出力の一貫性同じ書き味で揃う—
費用100名規模で月5,000〜10,000円程度0円
3社の無料を重ねるのは勧めません
  • そもそも無料枠がGoogleしか無いので、重ねようがありません
  • 鍵が3本になると、期限・残高・規約の管理も、障害の切り分けも3倍になります
  • 同じ生徒のカルテが日によって別の書き味になります。カルテは読み比べて使うものなので、ここが揺れると講師の信頼を早く失います
他塾へのご案内の型

「まずはGoogleの無料キーでお試しください。1件ずつお使いになる分には無料枠で足ります。 一括処理をお使いになるようになったら、有料キー（月数千円〜）へ切り替えてください。」

切り替えは鍵を差し替えるだけで、作り直しは要りません。

4. APIキーの取り方管理者

A. 無料で始める場合（Google Gemini）

  1. Googleアカウントで aistudio.google.com を開く
  2. 「Get API key」→「Create API key」を選ぶ
  3. 表示された文字列（AIza… で始まります）を控える。この画面を閉じると二度と表示されません
  4. 環境変数 GEMINI_API_KEY に設定する（→ 6章）

B. 有料で本運用する場合（Anthropic / Claude・推奨）

  1. console.anthropic.com で会社のメールアドレスのアカウントを作る
  2. Billing で会社名義のカードを登録し、残高を追加する（少額から可）
  3. API keys →「Create Key」で鍵を発行する（sk-ant-… で始まります）
  4. 環境変数 ANTHROPIC_API_KEY に設定する（→ 6章）
⚠ 鍵は「見せない・使い回さない」
  • 鍵はメールやチャットに貼らない（貼ったら発行し直す）
  • 塾ごとに別の鍵にする。1本を複数の塾で使い回さない
  • 使う人が変わったら、古い鍵は必ず失効させる

5. エラーが出たときの読み方責任者管理者

AIが使えなかったとき、講師の画面にはこの案内が出ます。講師に技術的な判断をさせない作りです。

つながるまなび ／ カルテ

Claude（Anthropic）の残高・利用枠が足りません（当社のキー）。プロバイダ側で残高を追加するか、別のAIに切り替えてください。解決しない場合は下の「ヘルプデスクに連絡」からお知らせください。
AI提供元の残高・利用枠が足りていません。残高を追加するか、別のAIに切り替えると動きます。
もう一度試す ヘルプデスクに連絡

種別ごとの対処

画面に出る内容原因管理者がすること

6. 管理者の設定作業管理者

① APIキーの設定（Vercel）

  1. Vercel にログインし、プロジェクト manabi-saas を開く
  2. Settings → Environment Variables を開く
  3. 下の表の名前と値を追加する（Production を選ぶ）
  4. Deployments から最新のものを Redeploy する（設定は再デプロイで反映されます）
名前値必須
ANTHROPIC_API_KEYClaudeの鍵（sk-ant-…）いずれか1つ
OPENAI_API_KEYChatGPTの鍵（sk-…）いずれか1つ
GEMINI_API_KEYGeminiの鍵（AIza…）いずれか1つ
RESEND_API_KEY問い合わせメール送信用任意
EMAIL_FROM差出人アドレス任意
SUPPORT_EMAIL_TO問い合わせ先（既定 info@kyouiku-koubou.com）任意
✕ やってはいけないこと

鍵をソースコードに直接書かないでください。GitHubに残ると、誰でも使える状態になります。必ず環境変数で設定します。

② 記録用のテーブル（初回のみ）

Supabase の SQL エディタで support-setup.sql を実行します。実行済みなら不要です。

③ 日常の確認

見るもの分かること
ai_error_logAIが失敗した記録。同じ種別が続いていたら鍵か残高の問題
support_requests講師から届いた問い合わせ。mail_status が skipped ならメール未設定

7. 費用の目安責任者

生徒100名・報告書800件／月・カルテ更新800回／月で試算した概算です。

用途目安（月額）
報告書の生成約 4,000円
カルテの更新約 3,000円
合計5,000〜10,000円程度

※ 使用量・文章量・モデルにより上下します。軽い処理（17項目の推定・シフト要約）は安いモデルへ自動で振り分けています。

8. 困ったときは

ヘルプデスク　info@kyouiku-koubou.com

画面の「ヘルプデスクに連絡」からお送りいただくのが最短です。エラーの詳細が自動で添付されるため、 状況を説明していただく必要はありません。
